**자료** 해당 층 건축 평면도 (2026-09-17 제공) · 집기 태그 `P-2F-xx` 기준 **2층**

## 1. 도면 모델은 정확합니다 — 치수열이 mm 단위로 일치

업로드하신 조닝 모델의 좌표를 도면 치수와 대조했습니다. **오차 0mm**입니다.

| 구간 | 모델 계산값 | 도면 표기 |
| --- | ---: | ---: |
| 좌측 벽면(L열) → 좌측 곤돌라군 | 951.0 | **951** |
| 좌측 곤돌라군 전체 폭 (엔드 포함) | 3,390.0 | **3,390** |
| 좌측군 → 우측군 (중앙 간격) | 1,000.0 | **1,000** |
| 좌측 벽 → 좌측군 | 1,366.0 | **1,366** |
| 우측군 → 우측 벽 | 1,366.0 | 1,360 *(6mm 차, §4 참조)* |
| 하단 뱅크 폭 | 7,520 | **7,520** |
| 하단 좌측 이격 | 1,502 | **1,502** |
| 하단 우측 이격 | 1,490 | **1,490** |
| 검산 | 1,502 + 7,520 + 1,490 = **10,512** | **10,512** |

곤돌라 열 간격도 위에서부터 1,395 / 1,379 / 1,295 / 1,295 / 1,405로 도면과 일치합니다.

**제 v7.1 기준안(56.8평)이 틀렸고 도면 모델(32.8평)이 맞다는 결론이 재확인됩니다.**

## 2. 새로 확인된 것 — 건물 그리드

| 항목 | 값 |
| --- | --- |
| 그리드 | X1 ~ X7, 총 **31,650mm** |
| 베이 간격 | 5,050 / 5,400 / 5,400 / 5,400 / 5,400 / 5,000 |
| 구조 | **5,400mm 반복** = 표준 기둥 그리드 |
| 약국 점유 | **X4 ~ X6, 2베이**로 읽힘 |

**산술 근거**: X4~X6 = 10,800mm, 매장 내부 10,512mm → 차이 288mm = **편측 144mm**.
150mm 경량벽 + 마감에 정확히 들어맞는 값입니다. 다만 도면상 경계선과 그리드선의
관계를 직접 확인하지는 못했으므로 **확정이 아니라 정합 추정**입니다.

## 3. ⚠️ 가장 중요한 발견 — 중앙 1,000mm가 통로가 아닐 수 있습니다

약국을 X4~X6으로 놓으면 **X5 그리드선의 매장 내 위치는 x ≈ 5,256mm** 입니다.
중앙 간격 구간은 x 4,756 ~ 5,756mm.

> **X5는 이 간격의 정중앙에 떨어집니다. 편차 0mm.**

1,000mm 간격의 한가운데에 기둥 그리드선이 오차 없이 지나가는 것은 우연으로 보기 어렵습니다.
**이 간격은 통로로 뚫어 놓은 것이 아니라, 기둥을 피하려고 생긴 이격일 가능성이 높습니다.**

### 기둥이 있을 경우 잔여 통로

| 기둥 크기 | 잔여 폭 (좌 / 우) |
| --- | --- |
| 400mm | 300 / 300 |
| 500mm | 250 / 250 |
| 600mm | 200 / 200 |

**어느 경우든 사람이 지나갈 수 없습니다.**

### 두 해석과 각각의 결과

| | ⓐ 기둥 있음 (이격) | ⓑ 기둥 없음 (교차 통로) |
| --- | --- | --- |
| 좌·우 횡단 | **불가** | 가능 |
| 매장 구조 | **좌·우 두 개의 독립 구역** | 하나의 매장 |
| 연결 지점 | 하단 B열 앞 통로 + 상단 W열 앞 통로, **두 곳뿐** | 중앙 포함 세 곳 |
| 조닝 함의 | 좌측 진입 → 좌측군, 우측 진입 → 우측군의 분리가 **설계 전제가 됨** | 진입과 무관하게 전 구역 접근 |
| 고민축 A~E | A(G1-D-3)·B(G3-D-2)는 좌측, C·D·E(G5)는 **우측 — 한 번에 비교 불가** | 비교 가능 |

**ⓐ라면 상담 카드(PDF p.17)의 "A는 G1 / B는 G3 / C·D·E는 G5" 안내가 물리적으로
좌측군과 우측군을 오가게 만듭니다.** 고객은 하단이나 상단을 돌아가야 합니다.
피부 고민 상담은 여러 축을 비교하는 흐름이므로, 이 분리는 상담 동선에 직접 영향을 줍니다.

**→ 도면에서 X5 위치의 기둥 유무를 확인해 주십시오. 이것 하나로 동선 모델이 갈립니다.**

## 5. 인접 조건 — 조닝에 영향을 주는 부분

| 방향 | 인접 | 성격 |
| --- | --- | --- |
| **하단(전면)** | 하부 OPEN 아트리움 보이드 | 좌·우 개방 진입 2개소 (1,502 / 1,490mm) |
| **우측** | **화장실(남) · 승강기 · MIRROR · AV** | 상시 통행 코어. 빈도 높고 체류 짧음 |
| **좌측** | 인접 테넌트(자체 진열 그리드 1,320×1,400) · **에스컬레이터/계단(UP·DN)** | 층 도착 지점. 둘러보는 흐름 |
| **상단(후면)** | 조제실 · POS 4대 | 후방 업무 |

### 검토가 필요한 지점 — B열 배치

현재 하단 진입부 배치는 다음과 같습니다.

- **좌측 B1–B4** (에스컬레이터 쪽): 여드름 / 흉터·상처 / 여행용품 / 피부 고민 찾기
- **우측 B5–B8** (화장실·승강기 쪽): 영양·선물 / PDRN / 장벽·민감 / **신제품 시험(B8)**

**B8 "New & Trial"이 화장실·승강기에 가장 가까운 끝단에 있습니다.**
이 위치는 통행 빈도는 가장 높지만 체류 시간이 가장 짧습니다.
반면 신규 브랜드 시험은 설명을 읽고 비교하는 **체류가 필요한 모듈**입니다.

두 가지 해석이 가능합니다.

- **재배치 논거**: 체류가 필요한 시험 모듈은 에스컬레이터 도착 쪽(둘러보는 흐름)이 유리.
  B8과 B4(고민 찾기)의 성격을 맞바꾸는 안.
- **유지 논거**: 화장실 인접은 **반복 노출**이 발생하는 자리라 신규 브랜드 인지에는 오히려 유리.

**어느 쪽도 통행 데이터 없이는 단정할 수 없습니다.** 오픈 후 진입별 유입과 B열 체류를
측정해 판단할 항목으로 남기시길 권합니다. 지금 단계에서는 문제 제기까지가 적정합니다.
