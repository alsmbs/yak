## 0. 요약

1. **선발 제품군 배치는 이미 완료되어 있습니다.** 367건(본진 326 + 추가 41)이 215칸에 배정되어
   업로드하신 두 JSON에 모두 반영돼 있습니다. 제가 다시 실행할 것은 없었습니다.
2. **다빈도 브랜드 상위 노출 기조도 지켜지고 있습니다.** A급 138건 중 109건(79%)이 S2–S3에 있습니다.
3. **그런데 더 큰 문제가 드러났습니다. 진열 충전율이 약 11%입니다.** 브랜드존을 논하기 전에
   이 건을 먼저 확인하셔야 합니다(§2).
4. 브랜드존은 **엔드캡 9개**에 배정했습니다(§4). 모듈 내 확장 여유 16칸은 **채우지 않았습니다** —
   충전율 11% 상태에서는 선반을 더 쓰는 것보다 기존 품목의 페이싱을 늘리는 것이 먼저입니다.
5. **르디퍼는 배정할 수 없었습니다.** 4개 SKU 전부가 분류 확인 대기(H) 상태입니다(§5).
6. 유리문 4m와 B열의 폭이 겹칩니다. 시뮬레이터가 6개 모듈을 지적합니다(§6).

## 2. ⚠️ 먼저 확인하셔야 할 것 — 진열 충전율 약 11%

### 2.1 계산

```
전체 선반 유효폭   259,275 mm   (865mm × 291칸 + 645mm × 24칸)
계획 페이싱          391 F
평균 페이싱 폭 70mm 가정 →  27,370 mm
                  ─────────────────
충전율              약 11%   (상품 배치된 215칸만 기준 15%)
```

865mm 선반 한 칸을 70mm 페이싱으로 채우려면 **12F**가 필요한데, **현재 평균은 1.8F**입니다.
215칸을 전면 충전하려면 약 2,514F가 필요하고 현재는 391F입니다.

### 2.2 포장 치수가 미입력이므로 범위로 봐도 결론은 같습니다

`05` 시트의 포장 가로는 **367건 전부 미입력**(`입력 대기`)입니다. 따라서 위 70mm는 가정치입니다.
다만 어떤 값을 넣어도 결론은 바뀌지 않습니다.

| 평균 페이싱 폭 | 충전율 |
| ---: | ---: |
| 50mm | 8% |
| 70mm | 11% |
| 100mm | 15% |
| 150mm | 23% |

일반적인 초도 진열 밀도(60~80%)와 큰 차이가 있습니다.

### 2.4 이전 진단의 정정

지난 회차에 저는 "G5-D-2가 5.9배 과적", "더마 충족률 41%"라고 말씀드렸습니다.
그것은 **카탈로그 1,706건의 후보 배정**을 기준으로 한 수치였습니다.
이번에 **실제 오픈 선정 326건**이 확정되면서 **문제가 반대로 뒤집혔습니다.**
과적이 아니라 **과소 충전**입니다. 이전 진단의 방향을 정정합니다.

### 2.5 선택지

| 방향 | 내용 | 비고 |
| --- | --- | --- |
| **A. 페이싱 확대** | 326품목의 F를 1.8 → 6~8로 상향 | 가장 현실적. `07` 시트의 "2주 후 1F 단위 조정"을 오픈 전으로 당기는 셈 |
| **B. 구색 확대** | 대체 후보 C 1,532건에서 추가 선정 | 초도 재고 부담 |
| **C. 선반 축소** | 5단 → 4단, 또는 일부 모듈 철거 | 집기 발주 전에만 가능 |
| **D. 연출 확대** | 브랜드존·POP·시즌 연출로 면적 소화 | §4가 여기에 해당 |

**포장 치수 입력이 선행되어야 A의 규모를 정할 수 있습니다.** 현재 `05`의 포장 가로·높이·깊이가
비어 있어 "이 선반에 몇 F가 들어가는가"를 계산할 수 없습니다. `02` 시트의 수용 검토도
215칸 전부 `치수 입력 대기`입니다.

| **X5 기둥 없음** | 중앙 1,000mm를 **통로로 확정**. 좌·우 구역 횡단 가능. 지난 회차에 제기한 분리 우려는 해소됐습니다. 상담 카드의 "A는 G1 / B는 G3 / C·D·E는 G5" 안내도 그대로 유효합니다 |
| **하단 4,000mm 유리문 ×2** | `door` 요소로 추가(좌 x 0~4,000 / 우 x 6,512~10,512), 진입 존 폭도 4,000mm로 조정 |

### 6.2 ⚠️ 유리문과 B열의 폭이 겹칩니다

B열은 **x 1,502 ~ 9,022**(7,520mm)에 하단 벽면을 따라 배치돼 있습니다.
유리문을 4,000mm씩 넣으면 다음이 겹칩니다.

| 유리문 | 구간 | 겹치는 모듈 |
| --- | --- | --- |
| 좌측 | x 0 ~ 4,000 | B1 · B2 · B3(일부) |
| 우측 | x 6,512 ~ 10,512 | B6(일부) · B7 · B8 |

시뮬레이터 진단이 **"출입구 접근공간 방해 — 좌측 유리문 4m 앞에 Acne Care 외 5건"** 으로 잡습니다.

**두 해석 중 어느 쪽인지 알려 주십시오.**

| | ⓐ B열이 고정 유리 뒤 윈도 진열 | ⓑ 유리문이 실제 통행 개구 |
| --- | --- | --- |
| 현행 B열 | 그대로 유지 | **B1~B3 · B6~B8 재배치 필요** |
| 실제 통행 개구 | 좌 1,502 / 우 1,490mm | 좌 4,000 / 우 4,000mm |
| 영향 | 없음 | B열 8모듈 중 6개 이동 — 40칸 재배치 |

ⓑ라면 하단 진입부 조닝(B1~B8의 좌 피부OTC / 우 더마 구성)을 다시 짜야 하므로
**오픈 전 확정이 필요한 항목**입니다.
