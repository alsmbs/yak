# K-Pharmacy Layout Studio — 약국 레이아웃·진열 시뮬레이터

약국의 **평면 배치(Layout) · 조닝(Zoning) · 진열 계획(Planogram)** 을 한 파일에서
설계하고, 3D로 검증하며, 리포트로 산출하는 브라우저 기반 도구입니다.
빌드 과정·서버·외부 런타임 의존성이 없으며, HTML 파일을 브라우저로 열면 바로 동작합니다.

| 파일 | 용도 | 대상 |
| --- | --- | --- |
| `pharmacy-layout-studio.html` | **정식판 (v7.0)** — 전체 기능 | 점포개발·MD·인테리어 실무 |
| `pharmacy-layout-lite.html` | **간략판** — 핵심 기능만 | 현장 약사·가맹 상담·초기 스케치 |

---

## 1. 이번 개정의 배경

기존 v6.1은 평면 편집기로서는 완성도가 높았으나, 두 가지가 실무 의사결정을 지원하지 못했습니다.

1. **3D가 "높이 있는 색 블록"에 그쳤다.** 직교에 가까운 비정통 투영, 회전과 무관하게
   고정된 면 음영, 단(段) 표현이 흰 선 몇 개뿐이어서 *어떤 매대의 몇 단에 무엇이 놓이는지*
   를 판단할 수 없었습니다.
2. **진열대별 배치를 조망할 단위가 없었다.** 단별 분류는 선택된 한 개 매대의
   인스펙터에서만 보였고, 매대를 식별할 코드 체계도, 매장 전체의 진열 계획을
   한 화면에서 비교할 수단도 없었습니다.

아래 개정은 이 두 문제를 축으로 진행했습니다.

## 2. 3D 렌더링 전면 재구현

`draw3D()` 를 폐기하고 캔버스 2D 기반의 소형 3D 파이프라인을 새로 작성했습니다.

### 2.1 카메라·투영

| 항목 | v6.1 | v7.0 |
| --- | --- | --- |
| 투영 | 사교(oblique) 유사 변환 | **원근 투영** (fov 44°, 근평면 클리핑) |
| 카메라 | yaw/pitch 슬라이더만 | **구면 궤도(orbit) + 팬 + 돌리**, 주시점 높이 제어 |
| 시점 | 자유 회전 1종 | **아이소 / 정면 / 평면 / 고객 시선(眼高 1,450mm)** 프리셋 |
| 조작 | 드래그 회전, 휠 확대 | 드래그 회전 · **Shift+드래그 팬** · 휠 돌리 · **방향키 미세 회전** · **클릭 선택** |

- 근평면 클리핑(Sutherland–Hodgman)을 구현해 **고객 시선 모드에서 카메라가 집기 사이로
  들어가도 화면이 깨지지 않습니다.**
- 렌더는 `requestAnimationFrame` 으로 병합되어 드래그 중 중복 그리기가 발생하지 않습니다.

### 2.2 음영·가시성

- **후면 제거(backface culling)**: 닫힌 입체의 뒷면을 제거해 폴리곤 수를 절반으로 줄이고
  화가 알고리즘의 정렬 오류를 구조적으로 제거했습니다.
- **램버트 음영 + 반구 앰비언트**: 면 법선 기준으로 계산하므로 회전에 따라 명암이 정상 변합니다.
  (v6.1은 꼭짓점 인덱스별 고정 보정값을 써서 회전해도 음영이 따라오지 않았습니다.)
- **카메라 추종 키 라이트**: 광원이 카메라 방위각을 30° 앞서 따라갑니다. 고정 광원을 쓰면
  회전 시 정면이 어두워져 분류 색상이 읽히지 않는 문제를 해결했습니다.
- **돌하우스 뷰**: 카메라와 매장 사이를 가리는 앞쪽 벽체만 자동 제거하고 안쪽 벽은 유지합니다.
- 바닥 그림자, 1m 바닥 격자, 매장 치수, 나침반, 조닝 색상 범례를 추가했습니다.

### 2.3 진열대 지오메트리 — 핵심 개선

단색 박스를 **실제 곤돌라 구조**로 전개합니다.

```
걸레받이 · 좌우 측판 · 배판(양면형은 중앙 배판) · 단별 선반판 · 최상단 캡
   + 단별 전면 구성 ─┬─ ① 분류 색상 단띠(가격 레일)
                     └─ ② 상품 페이싱 타일
   + 조닝 헤더 띠(매대 상단, 소속 존 색)
```

- **단띠(rail)** 는 각 단 하단에 놓이는 불투명 색 띠로, 해당 단의 중카테고리가 속한
  대카테고리 색을 씁니다. 선반 구조를 가리지 않으면서 단별 분류가 즉시 읽힙니다.
- **골든존(850–1500mm)** 에 걸치는 단은 금색 테두리로 강조됩니다.
- 양면 곤돌라(`shelf`)는 전·후면 모두에 단띠와 페이싱이 생성됩니다.
- 매대 본체는 소속 존 색을 옅게 섞어(78% 화이트 혼합) 칠해, 존 소속과 단별 분류를
  동시에 구분할 수 있습니다.
- **LOD**: 화면 투영 높이가 임계 이하인 단은 페이싱 타일과 라벨을 생략합니다.

### 2.4 라벨

- 매대 헤더(코드 · 이름 · 칸/단/높이)와 단별 라벨(`3단 · 오메가3`)을 분리했습니다.
- **겹침 제거(decluttering)**: 카메라에 가까운 순으로 배치하며 이미 놓인 라벨과
  겹치면 생략합니다. 배경 플레이트와 좌측 색상 바를 둬 어떤 배경에서도 판독됩니다.
- 골든존 단 라벨은 금색 테두리로 구분됩니다.
- **3D에서 매대를 클릭하면 2D 평면과 인스펙터가 동시에 선택**되고, 우측에 단별 계획이
  높이 구간(mm)과 함께 표시됩니다.

### 2.5 렌더 모드

`기본` · `높이 히트맵`(시야 차단 검토: 녹→황→적) · `골격`(와이어프레임)

## 3. 진열대별 배치의 명확화

### 3.1 진열대 코드 자동 부여

벽면 근접도로 매대를 분류해 코드를 부여합니다. 참조 플래노그램과 동일한 체계입니다.

| 접두 | 위치 | 정렬 |
| --- | --- | --- |
| `W` | 상단 벽면 | 좌 → 우 |
| `L` / `R` | 좌측 / 우측 벽면 | 위 → 아래 |
| `B` | 하단·입구부 | 좌 → 우 |
| `G` | 중앙 매대(곤돌라) | 위 → 아래, 좌 → 우 |

코드는 평면도 배지, 3D 라벨, 진열 계획표, CSV, 리포트에 일관되게 표기되며
인스펙터에서 수기 수정할 수 있습니다. (상단 툴바 `코드` 또는 자동 배치 시 자동 실행)

### 3.2 단 번호 체계 변경 ⚠️

**v6.1은 최상단을 1단으로 표기**했으나, 매대 실무와 참조 플래노그램은 최하단을 1단으로
셉니다. v7.0은 **표기를 최하단=1단으로 통일**했습니다.

- 내부 데이터 순서(`levelDetails[0]` = 최상단)는 변경하지 않았으므로 **기존 JSON은 그대로
  호환**됩니다. 바뀐 것은 화면 표기뿐입니다.
- 인스펙터·계획표·3D·CSV 모두 동일 기준을 사용하며, 각 단의 실제 높이 구간(mm)을 함께 표시합니다.

### 3.3 진열 계획표 (Planogram) — 신규

`진열 계획표` 버튼 또는 `P` 키.

- 전 매대를 **정면도 카드**로 펼쳐 한 화면에서 비교·수정합니다. 카드마다 코드, 이름,
  칸/단 수, 단별 분류 셀렉트, 분류 완성도가 표시됩니다.
- 골든존 단은 음영 처리됩니다.
- 검색(코드·이름·분류), 정렬(코드順 / 대카테고리順 / **미완성 우선**), 골든존만 보기.
- **단 구성 복사 → 다른 매대에 붙여넣기** (동일 구성 매대 열 일괄 적용).
- `미지정 단 채우기` — 매대의 대표 분류를 빈 단에 일괄 적용.
- `단 구성 제안` — 진열 원칙(골든존=주력, 상단=프리미엄, 하단=기본·대용량)에 따라
  대카테고리 내 중카테고리를 결정적으로 분배합니다. **초안 제안이며 전부 수정 가능합니다.**
- `진열 계획 CSV` — 매대×단 단위 전개표(코드, 단 번호, 높이 구간, 골든존 여부,
  대·중카테고리, 비고, 좌표, 규격)를 UTF-8 BOM으로 내보냅니다.

### 3.4 평면도(2D) 표현 강화

- 매대 상단에 **단별 색상 스트립**을 그려, 확대하지 않아도 각 매대의 단 구성과
  미지정 단을 즉시 식별할 수 있습니다.
- 매대 좌상단 외부에 **코드 배지**를 배치했습니다(도형과 겹치지 않음).
- 매대 본체를 옅게 칠해 색상 스트립이 도드라지도록 조정했습니다.
- 보조 라벨을 `2칸 · 3/5단 분류 · H2,100` 형식으로 바꿔 **분류 완성도를 평면에서 바로 확인**합니다.

### 3.5 인스펙터 단 편집기 재구성

- 단별 색상 칩 · 실제 높이 구간(mm) · 골든존 음영을 함께 표시합니다.
- `▲ ▼` 로 단 간 구성을 교체할 수 있습니다.
- `단 복사` / `붙여넣기` / `현재 분류 전 단 적용` / `비우기`.
- 진열 원칙 가이드를 상시 노출합니다.

## 4. 분석·진단 고도화

### 4.1 평가 축 재배분 (총점 100)

| 축 | v6.1 | v7.0 | 비고 |
| --- | --- | --- | --- |
| 동선 | 40 | 34 | 겹침·통로·출입구 |
| 조닝 | 25 | 21 | 분류 누락·존 불일치 |
| **진열** | – | **16** | **신규** |
| 운영 | 20 | 17 | 출입구·계산대·조제·창고 |
| 효율 | 15 | 12 | 점유율·조닝 적용률 |

**진열 축(16점)** = 단 분류 완성도 8 + 골든존 활용 6 + 코드 체계 2 − 중앙 고단 매대 감점(최대 2)

### 4.2 추가 진단 항목

- **단별 분류 미완성** — 미지정 단 비율 60% 미만 시 경고, 해당 매대로 이동 가능
- **골든존 활용 부족** — 골든존 단 중 미배정 비율
- **진열대 코드 미부여**
- **중앙 고단 매대 시야 차단 가능** — 1,800mm 초과 중앙 매대

### 4.3 리포트

- KPI에 **단 분류 완성도**, **골든존 활용률** 추가 (총 7개)
- **진열대별 단 배정** 섹션 신규: 코드·규격·단별 색상 칩 전개·골든존 충족(n/m)
- 인쇄·PDF 및 CSV 내보내기는 기존과 동일하게 동작합니다.

## 5. 기타 개선

- 상단 툴바에 `진열 계획표`, 캔버스 도구에 `코드` 버튼 추가
- 단축키: `P` 진열 계획표, `3` 3D 보기 (기존 `A` 진단 / `R` 리포트 / `F` 맞춤 / `G` 격자 유지)
- 신규 매대는 선택한 중카테고리를 전 단에 시드하므로 추가 직후 3D에 바로 반영됩니다
  (기존 JSON을 불러올 때는 저장된 값을 그대로 유지합니다)
- 예시 레이아웃이 코드·단별 분류까지 채워진 상태로 로드되어 기능을 바로 확인할 수 있습니다
- 진단 캐시 키에 코드·높이·단수·칸수를 포함해 재계산 누락을 제거했습니다
- 서로 다른 단 수의 매대 간 단 구성 붙여넣기 시 발생하던 예외를 수정했습니다

## 6. 간략판 (`pharmacy-layout-lite.html`)

정식판과 **같은 시각 언어**(존 색상, 골든존, 단띠·페이싱 3D, 코드 체계)를 유지하면서
학습 부담을 최소화한 단일 파일입니다. 외부 폰트·라이브러리 의존이 없습니다.

**포함**

- 매장 규격 입력(가로·세로·천장, 평 환산 자동)
- 매대 6종(벽면 매대 / 양면 곤돌라 / 엔드캡 / 냉장 쇼케이스 / 상담대 / 계산대) 클릭 추가
- 드래그 배치 · 격자 스냅(Alt 10mm) · 휠 확대 · 빈 공간 드래그로 화면 이동
- 대카테고리 6종 · 중카테고리 간소화 목록, 단별 분류 지정
- 진열대 코드 자동 부여(W/L/R/B/G), 조닝 영역 추가
- **3D 미리보기** — 동일 엔진 축약판(원근·후면 제거·카메라 추종 조명·단띠·페이싱·
  겹침 제거 라벨·4종 시점 프리셋·클릭 선택)
- 요약 지표 — 진열대 수, 총 단 수, 집기 점유율, 진열 계획 점수(단 분류 45 + 골든존 30 + 점유율 25)
- PNG · JSON 내보내기, 3D PNG 저장

**제외** (정식판에서 이용) — 도면 배경·축척 보정, 자동 매대열 배치, 초기 설계 제안,
레이어 패널, 겹침·통로 진단, 분석 리포트, 실행 취소, 회전, 주석·치수선, 세부 카테고리 전체 트리

## 7. 사용 방법

브라우저(Chrome / Edge / Safari 최신)로 HTML 파일을 직접 엽니다. 설치·서버 불필요.

**정식판 권장 순서**

1. `면적부터 시작` — 평수·형태로 외벽·조닝 초안 생성 (또는 `예시` 로 기능 확인)
2. 좌측에서 매대를 배치하거나 `매대열 자동 배치` 실행
3. 상단 `코드` 로 진열대 코드 부여
4. `진열 계획표`(P) 에서 단별 분류 확정 — `단 구성 제안` 으로 초안 후 수정
5. `3D 보기`(3) 에서 **고객 시선** 시점으로 골든존 배치와 시야 차단 검토
6. `설계 진단`(A) → `분석 리포트`(R) → CSV·PDF 산출

## 8. 한계와 주의

- 진단 점수, 골든존 판정, 통로 검토는 **기획 검토용 휴리스틱**입니다. 건축·소방·전기,
  의약품 보관 기준, 장애인 편의시설 등 **법정 기준 판정을 대신하지 않습니다.**
  시공 전 현장 실측과 관할기관 확인이 필요합니다.
- `단 구성 제안` 은 진열 원칙에 따른 **초안 생성기**이며, 실제 매출·재고·계약 조건을
  반영하지 않습니다. 반드시 검토 후 확정하십시오.
- 3D는 계획 검토용 표현이며 실측 렌더링·시공 도면이 아닙니다.
- 데이터는 브라우저 내(메모리 / localStorage)에만 저장됩니다. 보존이 필요하면
  **JSON 내보내기** 를 사용하십시오.
- 정식판은 본문 웹폰트(Paperlogy)를 CDN에서 불러옵니다. 오프라인 환경에서는
  시스템 기본 서체로 대체되며 기능에는 영향이 없습니다.
